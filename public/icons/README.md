# PWA Icons

Place the following icon files here for the PWA manifest:

- `icon-192.png` — 192x192 px (required for install prompt)
- `icon-512.png` — 512x512 px (splash screen)
- `icon-512-maskable.png` — 512x512 px with safe zone padding (Android adaptive icons)

Generate from your logo using: https://maskable.app/editor or any icon generator.

The maskable icon should have ~20% padding around the logo so Android doesn't clip it.
